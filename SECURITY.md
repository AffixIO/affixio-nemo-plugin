# Security Policy

## Reporting

Please report security issues to hello@affix-io.com with the subject `Security: affixio-nemo-plugin`.

Do not include live API keys, private customer data or production secrets in a report. If a reproduction needs sensitive context, describe the shape of the data and we will arrange a safer channel.

## Supported Versions

The current beta line is supported for security fixes while the package remains public and maintained.
