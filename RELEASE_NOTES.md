# Release Notes

## v0.1.0

Initial beta release of AffixIO NeMo Plugin.

Highlights:

- AffixIO API guard for NVIDIA NeMo Agent Toolkit tool execution.
- ALLOW, DENY and REVIEW decision handling.
- Conservative fail-closed default.
- Optional attestation and audit request flags.
- Typed async Python client.
- NeMo plugin entry point.
- Example workflow configuration.
- Test coverage for config, payloads, HTTP decisions, middleware and package contract.
